# Data Dictionary – Task 1

## Columns Description

| Column Name       | Description | Data Type |
|------------------|------------|-----------|
| Customer_ID      | Unique customer identifier | String |
| Customer_Name    | Name of customer | String |
| Date_of_Birth    | Customer birth date | Date |
| Gender           | Customer gender | String |
| Product          | Product purchased | String |
| Purchase_Amount  | Amount spent | Float |
| Purchase_Date    | Date of purchase | Date |
| Customer_Age     | Calculated age from DOB | Integer |
| Age_Group        | Young (<30) / Adult (>=30) | String |
